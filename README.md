# TTCN_H4IPNL
Build a custom Cinema Booking System: Hỗ trợ khách hàng xem danh sách phim, tra cứu lịch chiếu theo cụm rạp và phòng chiếu, chọn ghế ngồi trực quan trên sơ đồ phòng chiếu, đặt combo bắp nước và thanh toán online nhận vé điện tử (mã QR). Phân hệ quản trị cho phép cấu hình rạp, sơ đồ ghế, quản lý phim, xếp lịch chiếu và thống kê doanh thu.
