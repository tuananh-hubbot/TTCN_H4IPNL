# Sổ tay công cụ CineBook

| Công cụ | Vai trò | Trang tải |
|---|---|---|
| VS Code | Mở và chỉnh sửa source | https://code.visualstudio.com/ |
| Docker Desktop | Chạy frontend/backend/MySQL | https://www.docker.com/products/docker-desktop/ |
| Java JDK 21 | Biên dịch backend Java | https://adoptium.net/ |
| Node.js 22 | Chạy Angular trên máy | https://nodejs.org/ |
| MySQL Workbench | Xem và truy vấn MySQL | https://dev.mysql.com/downloads/workbench/ |
| Postman | Kiểm tra API | https://www.postman.com/downloads/ |
| Git | Quản lý phiên bản | https://git-scm.com/downloads |

Spring Boot và Angular là framework: source đã có sẵn; chạy bằng Docker không bắt buộc cài Maven/Angular CLI toàn cục.
